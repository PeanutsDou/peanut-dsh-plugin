# dsh-turn-ui

长会话阅读优化：聊天区左边缘的轮次导航条，点击短横杠跳转到对应轮次，并高亮当前正在查看的轮次。

## 组成

- **TurnRail（插件）**：`src/client/index.tsx` 注册到会话头部的 utilities 槽位，
  用 portal 在聊天区左边缘画一条 8px 悬浮细轨：
  - 短横杠为 2px 薄矩形，等间距从顶部排列，不随轮次数撑满高度；
  - 悬停显示“第 N 轮 / 运行中”，点击跳转到对应轮次；
  - 通过 `data-turn-tail` 锚点 + 滚动监听实时高亮当前轮；
  - 未加载的历史轮次按比例滚动。
- **设置**：设置 → 插件 → 可配置 →「轮次导航条」，`turnRailEnabled` 默认开启。

## 部署

按普通 DSH profile 插件部署（`cordis.patch.yml` 已带 insert 行）。

## 测试

插件为纯 client UI，主要依赖浏览器会话快照与 DOM 锚点；构建后通过真实 DSH
页面验证点击跳转、当前轮高亮与开关设置。
